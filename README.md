# Analyse des notes UNILU - Python Pandas
Projet d'analyse statistique réalisé dans le cadre de mon graduat Informatique & Statistiques à l'UNILU.

## 🎯 Objectif
Analyser un fichier de notes de 50 étudiants pour calculer les indicateurs de performance demandés par l'administration.

## 📊 Analyses réalisées
- Moyenne, médiane, mode de la classe
- Écart-type pour mesurer la dispersion des notes
- Taux de réussite >= 10/20 
- Identification des matières avec le plus d'échecs

## 🛠️ Technologies
- Python 3
- Pandas
- Jupyter Notebook

## 📈 Résultats clés
- Moyenne générale : 12.4/20
- Taux de réussite : 68%
- Écart-type : 3.2 → classe hétérogène
